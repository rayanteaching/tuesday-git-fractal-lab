# آزمایشگاه فرکتال کلاس گیت سه‌شنبه

از یک مخزن خالی در GitHub شروع می‌کنیم و با Python Turtle یک درخت فرکتال می‌سازیم. بعد رنگ‌ها و شکوفه‌های قابل کلیک را با دو Pull Request جدا اضافه می‌کنیم.

## از اینجا شروع کنید

- [درسنامهٔ کامل دانش‌آموز](LESSON.md) با کدها، فرمان‌ها و خروجی مورد انتظار هر مرحله
- [متن آمادهٔ دو Pull Request](PULL_REQUEST_TEXTS.md)
- [نسخهٔ چاپی جزوه](handout/Tuesdays_Git_Fractal_Lab_A4.pdf)

**ریپوی کلاس مرجع تمرین است.** مطابق درسنامه در حساب خودتان یک مخزن خالی به نام `fractal-lab` بسازید. کامیت‌ها، شاخه‌ها و PRهای تمرین را در همان مخزن شخصی انجام دهید.

## نسخه‌های قابل مقایسه

| نسخه | کد کامل |
| --- | --- |
| درخت سفید و کامیت پایه | [main.py](https://github.com/rayanteaching/tuesday-git-fractal-lab/blob/checkpoint-white/main.py) |
| درخت رنگی پس از PR رنگ | [main.py](https://github.com/rayanteaching/tuesday-git-fractal-lab/blob/checkpoint-colors/main.py) |
| فرکتال نهایی با شکوفهٔ قابل کلیک | [main.py](main.py) و [decor.py](decor.py) |

برای اجرای نسخهٔ نمونه، `main.py` را در Thonny باز کنید و F5 بزنید. برای کاشت یک شکوفه، داخل پنجره کلیک چپ کنید.
